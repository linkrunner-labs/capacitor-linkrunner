# Linkrunner Capacitor SDK

A Capacitor plugin for integrating Linkrunner functionality into your Capacitor applications.

## Requirements

- Capacitor 5.0.0 and above
- iOS 15.0+ / Android 5.0 (API level 21) and above

## Documentation

For setup instructions, usage examples, and API reference, please visit: [Linkrunner Capacitor SDK Documentation](https://docs.linkrunner.io/sdk/capacitor)
